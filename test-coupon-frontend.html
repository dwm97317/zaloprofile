🎯 功能特性

  • 优惠券列表展示（按 sort 排序）
  • 优惠券卡片（渐变色、圆角设计）
  • 领取按钮（三种状态：可领取、已领取、已抢光）
  • 乐观更新 UI（领取后立即更新界面）
  • 加载状态（骨架屏）
  • 空状态提示
  • 错误处理和重试
  • 下拉刷新
  • Toast 提示
  • 多语言支持（泰语、中文）

🚀 测试步骤

前提条件：
  • 后端 API 已部署并运行
  • 已有测试用户 token
  • 数据库中有可领取的优惠券

1. 启动开发服务器

cd zalo_mini_app-master
npm run dev

2. 访问领券中心

方式一：从"我的"页面进入

1. 访问 http://localhost:3000/mine
2. 点击"领券中心"入口

方式二：直接访问

http://localhost:3000/coupon/center

3. 测试功能

  • ✓ 查看优惠券列表是否正确显示
  • ✓ 检查优惠券颜色是否正确（蓝/红/紫/黄）
  • ✓ 点击"立即领取"按钮
  • ✓ 验证按钮状态变为"已领取"
  • ✓ 检查 Toast 提示是否显示
  • ✓ 尝试重复领取（应该显示"已领取"）
  • ✓ 测试下拉刷新功能
  • ✓ 测试网络错误重试
