## Notes

- 所有任务都应该遵循 LINE 主题设计规范
- 确保所有文本都有泰语翻译
- 所有动画时长控制在 200-300ms
- 圆角使用 16px 或更大
- 主色使用 LINE 绿色 (#00B900)
- 字体大小不小于 14px
- 所有表单都需要验证
- 所有 API 调用都需要错误处理
- 优先实现核心功能，然后优化 UI 和动画
