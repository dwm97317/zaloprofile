# 钱包余额功能 - 测试指南

## 📋 测试概览

**功能**: 钱包余额显示、余额明细、充值记录  
**测试范围**: Phase 1 核心功能  
**测试环境**: 开发环境 (localhost:9000)

---

## 🎯 测试前准备

### 1. 启动开发服务器

```bash
cd zalo_mini_app-master
npm run dev
```

### 2. 确认后端API可用

确保以下API端点正常工作：
- `POST /api/user/detail` - 获取用户信息
- `GET /api/user/balanceLog` - 获取余额明细

### 3. 登录测试账号

使用有余额记录的测试账号登录系统

### Test Case 10: API数据映射

**测试API**: `GET /api/user/balanceLog`

**测试步骤**:
1. 打开浏览器开发者工具
2. 切换到Network标签
3. 在余额明细页面切换Tab
4. 查看API请求和响应

**预期请求**:
```
# 全部记录
GET /api/user/balanceLog?page=1&wxapp_id=10001&token=xxx

# 充值记录
GET /api/user/balanceLog?page=1&scene=1&wxapp_id=10001&token=xxx

# 消费记录
GET /api/user/balanceLog?page=1&scene=2&wxapp_id=10001&token=xxx
```

**预期响应**:
```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "list": {
      "total": 100,
      "per_page": 15,
      "current_page": 1,
      "data": [
        {
          "log_id": 1,
          "money": "200.00",
          "describe": "在线充值",
          "remark": "",
          "sence_type": 1,
          "create_time": 1705392000
        }
      ]
    }
  }
}
```

**验证点**:
- ✅ 请求URL正确
- ✅ scene参数正确传递
- ✅ 响应数据结构正确
- ✅ 前端正确解析数据
