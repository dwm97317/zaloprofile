## 🎯 项目目标

将前端"我的"页面的硬编码余额改为显示真实数据，并提供完整的余额管理功能。

## 📊 当前完成度

### 后端 (90%)
- ✅ 余额查询 API
- ✅ 余额变动日志
- ✅ 充值功能
- ✅ 转账凭证上传
- ⚠️ 转账凭证列表 API (待开发)

### 前端 (30%)
- ⚠️ 余额显示 (硬编码)
- ⚠️ 余额页面 (静态)
- ❌ 余额明细页面 (未实现)
- ❌ 转账记录页面 (未实现)

## 📝 核心用户故事

### Phase 1: 核心功能 (高优先级) 🔴

1. **US-001**: 查看当前余额 (2 故事点)
   - 在"我的"页面显示真实余额
   - 币种改为泰铢 (฿)

2. **US-002**: 查看累计充值和消费 (3 故事点)
   - 显示累计充值金额
   - 显示累计消费金额

3. **US-003**: 重构余额详情页面 (5 故事点)
   - 按照参考截图重新设计
   - 蓝色卡片 + 3个功能入口

4. **US-004**: 查看余额明细 (8 故事点)
   - 创建新页面 `/mine/balance/log`
   - Tab切换：全部/充值/消费
   - 列表显示所有余额变动

### Phase 2: 充值功能 (中优先级) 🟡

5. **US-005**: 在线支付充值 (3 故事点)
   - 选择套餐或自定义金额
   - 调起支付

6. **US-006**: 银行转账充值 (5 故事点)
   - 上传转账截图
   - 填写转账信息
   - 提交审核

7. **US-007**: 查看转账凭证状态 (5 故事点)
   - 显示审核状态
   - 查看审核结果
