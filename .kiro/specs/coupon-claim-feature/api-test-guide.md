## 🎯 测试用例

### 测试1: 获取优惠券列表

**接口**: `GET /api/coupon/lists`

**请求参数**:
- `coupon_type` (可选): 0=满减券, 1=折扣券

**预期结果**:
```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "list": [
      {
        "coupon_id": 1,
        "name": "满100减10",
        "color": {"text": "blue", "value": 10},
        "coupon_type": {"text": "满减券", "value": 10},
        "reduce_price": "10.00",
        "min_price": "100.00",
        "expire_type": 10,
        "expire_day": 7,
        "is_receive": false,
        "state": {"text": "", "value": 1}
      }
    ]
  }
}
```

**验证点**:
- ✅ 返回 code = 1
- ✅ list 数组包含优惠券数据
- ✅ is_receive 字段正确标识是否已领取
- ✅ state.value = 1 表示可领取

---

### 测试2: 领取优惠券

**接口**: `POST /api/coupon/receive`

**请求参数**:
- `coupon_id`: 优惠券ID

**预期结果**:
```json
{
  "code": 1,
  "msg": "领取成功",
  "data": []
}
```

**验证点**:
- ✅ 首次领取返回 code = 1
- ✅ 重复领取返回 code = 0, msg = "该优惠券已领取"
- ✅ 已发完的优惠券返回 msg = "优惠券已发完"
- ✅ 已过期的优惠券返回 msg = "优惠券已过期"

---

### 测试3: 获取可用优惠券

**接口**: `GET /api/coupon/enablecoupon`

**请求参数**:

**预期结果**:
```json
{
```

## 🐛 常见问题

### Q1: 获取列表时返回空数组
**原因**: 数据库中没有公开的优惠券（is_open = 0）
**解决**: 检查数据库 `yoshop_coupon` 表的 `is_open` 字段

### Q2: 领取时提示"优惠券不存在"
**原因**: coupon_id 不正确或优惠券已被删除
**解决**: 从列表接口获取正确的 coupon_id

### Q3: 领取时提示"该优惠券已领取"
**原因**: 用户已经领取过该优惠券
**解决**: 这是正常的防重复领取机制

### Q4: Token 认证失败
**原因**: 未提供 token 或 token 无效
**解决**: 
- 浏览器测试: 先登录系统，测试页面会自动使用当前登录状态
- PHP 脚本: 修改脚本中的 `$token` 变量
