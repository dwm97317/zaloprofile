## 📐 Component Dimensions

### Hero Section
- Height: Auto (padding: 24px)
- Background: Gradient with animated icons
- Progress steps: Max-width 512px, centered

### Package Cards
- Width: 100% (single column)
- Height: Auto
- Border-radius: 16px
- Padding: 12px
- Gap between cards: 12px

### Selection Cards (Route/Destination/Services)
- Width: 100%
- Height: Auto
- Border-radius: 16px
- Padding: 16px
- Border: 2px solid
- Gap between options: 8px

### Icon Sizes
- Section header icons: 48px × 48px (text-2xl)
- Option icons: 40px × 40px (text-xl)
- Info chip icons: 14px (text-sm)

### Cost Summary Bar
- Position: Fixed bottom
- Height: Auto (padding: 16px)
- Max-width: 512px (lg breakpoint)
- Shadow: 2xl
- Z-index: 20

## 🎭 Animation Details

### Hero Section
```javascript
// Floating icons
duration: 20-34s (staggered)
movement: Random X/Y positions
rotation: 0° to 360°
opacity: 0.1
```

### Progress Steps
```javascript
// Step circles
initial: scale(0.8), opacity(0)
animate: scale(1), opacity(1)
delay: index × 0.1s

// Progress line
initial: width(0)
animate: width(100%)
duration: 0.5s
```

### Selection Cards
```javascript
// Card entrance
initial: opacity(0), scale(0.95)
animate: opacity(1), scale(1)

// Tap effect
whileTap: scale(0.98)

// Selected checkmark
initial: scale(0)
animate: scale(1)
transition: spring
```

### Cost Updates
```javascript
// Number animation
initial: y(-10), opacity(0)
animate: y(0), opacity(1)
exit: y(10), opacity(0)
mode: wait
```

### Summary Bar
```javascript
// Entrance
initial: y(100), opacity(0)
animate: y(0), opacity(1)
transition: spring (damping: 25, stiffness: 300)
```

## 📱 Responsive Breakpoints

### Mobile (< 768px)
- Single column layout
- Full-width cards
- Sticky summary bar at bottom
- Touch-optimized (min 44px targets)
- Compact package cards

### Tablet (768px - 1024px)
- Same as mobile (optimized for portrait)
- Slightly larger text
- More padding

### Desktop (> 1024px)
- Max-width container (512px)
- Centered layout
- Hover effects enabled
- Larger click targets

## 🎪 Micro-interactions

### 1. Card Selection
- Tap: Scale down to 0.98
- Border color transition: 300ms
- Background color transition: 300ms
- Checkmark: Spring animation

### 2. Checkbox Toggle
- Checkmark: Scale from 0 to 1
- Border color: Instant change
- Background: Instant change

### 3. Cost Updates
- Number: Slide up/down animation
- Duration: 200ms
- Easing: ease-in-out

### 4. Button Press
- Scale: 0.95 on active
- Shadow: Increase on hover
- Transition: 150ms

### 5. Image Click
- Opacity: 0.8 on hover
- Cursor: pointer
- Transition: 200ms
